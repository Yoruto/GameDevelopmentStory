# 场景默认业务规则（选型与实现必读）

本文件是**业务规则库**：每个原子能力一条「作用 + 推荐 + 要点」，再附「场景组合速查」为常见场景指路。
命中后按推荐执行，不向开发者问「用哪个能力」；默认类写入需求单「规则 / 静默假设」标「默认」，开发者一句话可推翻。
每条规则给出**技能文档路径**（工作区 `skills/<技能 ID>/SKILL.md`），实现时直接读对应文件确认参数/约束/返回，无需检索。

## 规则模板

| 作用 | 这个业务干什么 |
| 分类 | `必接`（安全红线，门禁强制）或 `默认`（体验/运营默认，自检） |
| 推荐 | 哪些场景推荐怎么做（组合由 Agent 按场景挑选，不预设固定链路） |
| 要点 | 契约硬点与失败兜底 |
| 技能文档 | 对应技能 SKILL.md 路径 + JS Path（参数/约束/返回以该文件为准） |
| 防什么失败 | 必须能回答这个失败，答不出就不加 |

## 原子能力

### R-01 内容安全检测（必接）

| 字段 | 内容 |
| --- | --- |
| 作用 | 提交文本/生成内容前的敏感内容检测 |
| 分类 | `必接` |
| 推荐 | 页面有用户可提交文本（输入框/表单/可编辑内容）时，提交前调用，检测通过（`code === 200 && data === true`）才允许提交 |
| 要点 | `data === false` 拦截并提示；`401` 提示登录；`500` 友好兜底且不放行 |
| 技能文档 | `skills/colorbox-security-check-audit/SKILL.md` → `window.ColorboxAI.security.checkAudit(content)` |
| 防什么失败 | 违规内容上线/入库；异常时静默放行 |

> **门禁**：implement 阶段机器检查——页面含文本输入但未调用 `window.ColorboxAI.security.checkAudit` 即拦截。

### R-02 原生分享（默认）

| 字段 | 内容 |
| --- | --- |
| 作用 | 唤起微信/微博原生分享面板 |
| 分类 | `默认` |
| 推荐 | 页面有「分享到微信/微博」诉求时（分享活动/结果/海报） |
| 要点 | 用户主动点击触发；分享链接必须是完整 `http(s)`，禁止占位符/`#`；有门槛（未登录、未开始、名额满等）先提示；成功/取消/失败都给反馈 |
| 技能文档 | `skills/colorbox-social-share/SKILL.md` → `window.ColorboxAI.social.share({ title, link, text, imageUrl })` |
| 防什么失败 | 分享突兀无引导、链接无效或条件不满足时用户白点 |

### R-03 社区发帖（默认）

| 字段 | 内容 |
| --- | --- |
| 作用 | 拉起发帖页面并预填标题/正文/图片/话题，用户确认后发布 |
| 分类 | `默认` |
| 推荐 | 想让用户以发帖形式传播或沉淀 UGC 时（如生成海报后引导发帖）：先校验登录，图片先经上传拿 CDN，再用发帖编辑器预填海报图+活动文案+活动话题（绑定话题便于运营回流） |
| 要点 | 必须走该接口，禁止手写 Schema 或 `location` 跳转；唤起的图片必须先用 `oss-uploadFile` 上传拿 CDN 地址；海报含用户输入文本时先过 R-01；唤起失败/取消/成功都要给用户反馈 |
| 技能文档 | `skills/colorbox-request-bbs-open-post-editor/SKILL.md` → `window.ColorboxAI.request.bbs.openPostEditor({ title, content, imageUrl, topicId, tagId })` |
| 防什么失败 | 发帖链路断裂、违规内容发文、未绑定活动话题导致回流与运营无法追踪 |

### R-04 图片上传（默认）

| 字段 | 内容 |
| --- | --- |
| 作用 | 图片/文件直传 Hupu OSS 并返回 CDN 地址 |
| 分类 | `默认` |
| 推荐 | 需要线上图片地址时（晒图、头像、发帖配图、截图存证） |
| 要点 | 依赖登录态，未登录先引导登录再上传；单文件 ≤10MB；UI 有 Loading，失败可重试；禁止手写上传逻辑 |
| 技能文档 | `skills/colorbox-oss-upload-file/SKILL.md` → `window.ColorboxAI.oss.uploadFile({ file })` |
| 防什么失败 | 未登录白操作；上传失败无反馈/无重试 |

### R-05 登录态（默认）

| 字段 | 内容 |
| --- | --- |
| 作用 | 判断当前是否已登录并读取用户资料 |
| 分类 | `默认`（前置辅助） |
| 推荐 | 调用依赖登录态的能力（上传/发帖/写接口）前先校验；未登录引导登录再放行后续动作 |
| 要点 | 以 `data.islogin` 判断登录态；`code !== 200` 用返回的 `message` 友好提示 |
| 技能文档 | `skills/colorbox-auth-get-user-info/SKILL.md` → `window.ColorboxAI.auth.getUserInfo()` |
| 防什么失败 | 未登录时继续执行后续动作，用户白操作后才发现报错 |

### R-06 激励广告（默认）

| 字段 | 内容 |
| --- | --- |
| 作用 | 玩家观看激励视频获得抽奖次数/游戏内权益（活动与广告位由平台自动绑定，无需配置） |
| 分类 | `默认`（玩法收益类） |
| 推荐 | 需要「看广告得奖励/次数」玩法的抽奖或权益兑换页面：初始化用 `getActivityTaskState()` 展示剩余次数与 reward 任务；用户点击「看视频领奖励」→ `completeRewardVideo()`，`code === 200 && data.rewarded === true` 才视为奖励到账并刷新状态；抽奖玩法用 `consumeActivityChance()` 消耗一次次数（`data.prize === null` 表示未中奖，不是失败） |
| 要点 | 必须由用户主动点击触发，禁止在页面加载/循环/轮询/自动重试中调用；激励流程进行中禁用按钮，同一时间只允许一个流程；禁止自行补发奖励、禁止直接调用 Bridge 或任务接口；仅虎扑 App 内生效，站外/未登录返回 403（`APP_REQUIRED` / `LOGIN_REQUIRED`），由页面引导 |
| 技能文档 | 聚合入口 `skills/colorbox-vatask/SKILL.md`（三条链路与组合方式）；子技能 `skills/colorbox-vatask-complete-reward-video/SKILL.md`、`skills/colorbox-vatask-get-activity-task-state/SKILL.md`、`skills/colorbox-vatask-consume-activity-chance/SKILL.md` → `window.ColorboxAI.vatask.*` |
| 防什么失败 | 奖励未到账就发放或自行补发；重复/自动触发激励视频；站外/未登录无提示；剩余次数与状态不同步 |

## 场景组合速查

| 场景 | 推荐组合 | 要点 |
| --- | --- | --- |
| 用户可提交文本/表单 | R-01 | 检测通过才提交（必接） |
| 分享到微信/微博 | R-02 | 用户主动点击 + 完整链接 |
| 生成海报后在社区发帖 | R-05 + R-04 + R-03 | 海报含用户文本先过 R-01；图片先上传拿 CDN；绑定活动话题 |
| 晒图/头像等需要线上图片 | R-04 | 未登录先引导登录；≤10MB |
| 激励广告（看视频得次数/抽奖） | R-06 | 主动点击触发；奖励以原生确认到账为准；仅 App 内 |
