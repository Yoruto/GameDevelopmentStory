# 排行榜合并 · 改动清单（已有改造）

- 基线：`h5/index.html` 及其 `h5/css/`、`h5/js/`（不重写，只改榜单相关部分）
- 改动幅度：**改规则**（排序口径 + 掉榜停售门槛都动了） → 须看预览并确认
- 数值源：`activity/config.json`（改完跑 `scripts/sync_config.py` 同步到 `h5/config.json` 与 `h5/js/config.generated.js`）

## 1. 榜单块数：两块 → 一块

| | 内容 |
|---|---|
| 位置 | share 页（`.studio-only` 市场卡内） |
| 原样 | 「月销量排行」（按本月销量，前 10）＋「月活跃排行」（仅长线运营游戏，按月活，前 10，附提示「仅长线运营游戏，按月活排序，前 10。」） |
| 新样 | 只留一块「排行榜」：长线与单机同榜，按本月销量，前 15；月活跃排行整块删除（含标题、提示、渲染逻辑、数据接口） |

## 2. 排序口径

| | 内容 |
|---|---|
| 位置 | 榜单排序规则 |
| 原样 | 月销量榜按本月实销排；月活跃榜按月活排，且**只收长线** |
| 新样 | 一律按本月实销降序，不分类型、不给长线加权。长线不再因为「长线」在榜上占优 |

## 3. 行内显示

| | 内容 |
|---|---|
| 位置 | 榜单每一行 |
| 原样 | `1. 本公司 · 《标题》` —— 右侧 `本月实销 · 均分` |
| 新样 | 右侧一律 `本月实销 · 均分`；长线行在标题后多一个「长线」小标，**不再显示月活** |

月活在榜单上彻底退场：它本来就是实销 ×1500 反推的镜像值，既不影响名次也不提供新信息，
却占掉行尾约 100px 的宽度（实测消除后长标题的截断从 60px 降到 0）。

## 3b. 下月发售：一行一款

| | 内容 |
|---|---|
| 位置 | 生涯档 HQ「情报」卡 · `#hq-next-releases` |
| 原样 | 单行拼串：`下月发售：A · B · C · D · E 等 7 款`——名单一长就看不出有几款，整行换行还会顶高卡片 |
| 新样 | 标题一行（`下月发售`），其下**一款一行**；长线款带「长线」小标；超过 5 款时末行 `等 N 款`（N 是**剩余**款数，不是总数——一行一款之后总数会被读成「还有这么多」） |

数据源与口径都没变（`sim.careerYearReleases` 取下个月的名单）。上限 5 行只为防卡片被顶高：
实测每月名单长度分布为 1 款 129 个月 / 2 款 88 / 3 款 29 / 4 款 19 / 5 款 10 / 6 款 2，**最长 6 款**，
所以 5 行上限最多只会截掉 1 款，且截断时会明说「等 N 款」。

## 4. 席位数与掉榜停售门槛

| | 内容 |
|---|---|
| 位置 | 榜单席位（`lifecycle.chartSize`）与「掉榜停售」判定，以及垫底的填充游戏（`lifecycle.chartFillers`） |
| 原样 | 30 席；填充游戏 30 条，月实销 7200 递减到 **900**；掉榜门槛 ≈ **900 份** |
| 新样 | 15 席；填充游戏裁成 15 条，月实销改为 7200 递减到 **1800**；掉榜门槛 ≈ **1800 份** |
| 影响 | 经营档中游作品比现在难活一档。**这是本次最实质的难度变化** |

> 注意：`chartSize` 同时是掉榜判定席位与榜单展示席位，两者现在同为 15（改动前分别由 `chartSize=30` 与 `ranking.size=10` 控制）。改这个数必须同步重排 `chartFillers` 值域，否则门槛会意外跳变。

### 9.3 实测发现并修掉的问题（含上一轮）

**① 榜单文案的真正来源是 `config.copy`，不是 HTML（重要）**
`paint.js:886-889` 用 `copy.chartTitle` / `copy.chartHint` 覆盖 `index.html` 里的文本。
只改 HTML 的话游戏里仍显示旧的「本月畅销榜」和提到「假游戏填满」的旧说明。
→ 已改为改 `activity/config.json` 的 `copy` 段（`chartTitle` / `chartHint` / `chartDropBoxedNote`）。

**② 长标题换行把行高从 31px 顶到 47px，15 行在 360×640 上被底部坞切掉末尾三行**
实测 `rowsFullyVisible = 12/15`，第 13 行起不可见（`bodyOverflowY: auto`，得滚动才看得到）。
→ `app.css` 给 `#month-chart .item` 加单行约束：标题省略号、数值不换行、行距 8px→6px。

**③ 数值块固定占 174px，反过来把游戏名整个挤没**
实测 360×640 下出现「6. 拳头游戏 · …」这类**游戏名完全不可见**的行（标题被省略 134px）。
→ 把「发行商」与「游戏名」拆成两个 flex 子项，发行商收缩权重 100、游戏名 1：
宽度不够时先牺牲发行商、保住游戏名。**再加上本轮去掉月活，390 下标题零截断。**


**另一条实测结论**：生涯档（当前唯一可玩档位，`career.js` 里 `mode: "career"` 写死）**不进填充游戏**（`chartEntries` 只在非 career 档加 `chartFillers`），所以生涯榜上只有真实作品；§4 的填充游戏/门槛变化只对经营档生效，经营档目前在实机里没有入口（仅 `#app.mode-company` 的 CSS 分支存在）。
